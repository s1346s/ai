[1] 로지스틱 회귀분석(Logistic Regression)

- 목적: Y값이 둘 중 하나(0 또는 1)인 경우 예측하는 이진분류 모델
- 예시: 질병 유무, 스팸메일 여부, 구매 여부 등

- 출력: 0~1 사이의 '확률'
   -> 0.5 이상이면 1, 0.5 미만이면 0으로 분류

- 사용되는 함수: 시그모이드(sigmoid) 함수
   sigmoid(z) = 1 / (1 + e^-z)
   z = WX + b (선형결합)

- 손실함수(loss): Binary Cross Entropy(이진 교차 엔트로피)
   - 모델이 얼마나 오차를 내는지 계산

[2] 분류분석(Classification)

- 목적: 데이터를 기준에 따라 '범주(label)'로 나누는 것
- 종류:
   1) 이진분류 (0/1)
   2) 다중분류 (여러 클래스)
   3) 다라벨분류 (2개 이상 정답 가능)

- 예: 고양이/개 분류, 질병종류 분류, 글의 감정 분석 등

- 출력층 활성화 함수:
   - 이진분류: sigmoid (출력 1개)
   - 다중분류: softmax (출력 n개)

- 손실함수:
   - 이진분류: binary_crossentropy
   - 다중분류: categorical_crossentropy

- metrics(평가지표):
   1) accuracy (정확도)
   2) precision (정밀도)
   3) recall (재현율)
   4) f1-score (정밀도+재현율 조화평균)

- 데이터 분리:
   train(학습) / validation(검증) / test(평가)
   -> 모델이 과적합되는지 확인하기 위해 반드시 분리함

- 원핫인코딩(one-hot encoding):
   - 다중분류에서 타겟(y)을 모델이 이해할 수 있게 변환
   예: 클래스 3개일 때
      0 → [1,0,0]
      1 → [0,1,0]
      2 → [0,0,1]

- 정규화 / 스케일링:
   입력변수(X)의 범위를 0~1 or -1~1로 조정
   -> 학습속도 증가, 성능 향상

- 혼동행렬(Confusion Matrix):
   실제값 vs 예측값 비교표
           예측 긍정   예측 부정
   실제 긍정   TP         FN
   실제 부정   FP         TN
   - 성능 평가에 매우 중요
