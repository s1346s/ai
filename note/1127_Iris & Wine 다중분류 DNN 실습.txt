wine 품질 등급예측 (다중분류)

(1) 데이터 불러오기

* winequality-red.csv에는 와인의 화학적 성분 11개 + 품질 등급(3~8)이 포함됨
* 결측치 없음

(2) 독립변수(X) / 타겟변수(y) 분리

* X: 와인의 성분 11개
* y: 품질 등급(3~8)

(3) 독립변수 스케일링(StandardScaler)

* 화학성분마다 단위와 크기가 다름
* 신경망에서 학습 안정성을 위해 평균 0, 표준편차 1로 변환
* 학습셋 기준으로 fit 후 전체 데이터 transform 함

(4) 타겟변수 원핫인코딩(get_dummies)

* 품질 등급은 다중분류(3~8의 6개 클래스)
* categorical_crossentropy 사용을 위해 원핫인코딩 수행
* 예: 품질 5 → [0,0,1,0,0,0]

(5) 훈련셋 / 테스트셋 분리(train_test_split)

* train_size=0.7 (70% 학습, 30% 테스트)
* stratify 옵션: 클래스 비율을 동일하게 유지하도록 층화 추출
* random_state 고정하여 재현성 확보(항상 같은 비율로 섞임)

2. 모델 구성 

* 입력층(Input): 11개 (와인 화학 성분)
* 은닉층(Dense): 50 → 50 → Dropout(0.1) → 30
* 활성화 함수: ReLU
* 출력층(Dense): 6 (품질 6개 클래스), softmax 사용
* softmax: 각 클래스의 확률로 변환하여 다중분류 수행

3. 모델 학습 설정 

loss: categorical_crossentropy
optimizer: adam
metrics: accuracy

categorical_crossentropy
→ 원핫인코딩된 타겟을 사용한 다중분류용 손실함수

adam
→ 학습률 자동 조절이 되는 최적화 알고리즘

accuracy
→ 전체 샘플 중 정확하게 맞춘 비율

4. 모델 학습 (Callbacks 사용)

(1) ModelCheckpoint

* 검증 정확도(val_accuracy)가 개선될 때마다 자동 저장
* 가장 성능이 좋은 모델을 자동으로 보관

(2) EarlyStopping

* 검증 Loss(val_loss)가 일정 epoch 동안 개선되지 않으면 학습 조기 종료
* 과적합 방지

(3) CustomHistory

* epoch마다 loss, accuracy, val_loss, val_accuracy 출력

5. 모델 평가 

(1) 학습곡선 그래프

* train_loss vs val_loss, train_acc vs val_acc
* 과적합 여부 판단

  * train_loss ↓, val_loss ↑ → 과적합 신호

(2) 테스트셋 평가(model.evaluate)

* 최종 loss, accuracy 계산
* 예: accuracy ≈ 0.64 (64%)

(3) 혼동행렬 (Confusion Matrix)

* 실제값(실제 품질) vs 예측값(모델의 품질 예측) 비교
* 클래스별 분류 오류 파악 가능

예:
실제 8 중 일부가 5로 예측됨 → 고급 품질과 중간 품질이 유사하다는 의미

6. 모델 저장 및 사용

 model.save()
→ 학습이 끝난 모델을 직접 저장(마지막 epoch 모델)

 ModelCheckpoint
→ 학습 중 가장 성능이 좋은 모델 자동 저장
→ 보통 실무에서는 이 모델을 사용

(1) 모델 불러오기
load_model('파일경로.h5')

(2) 새로운 데이터 예측

* 입력 데이터 스케일링 반드시 필요
* model.predict → softmax 확률 출력
* argmax → 가장 높은 확률의 품질 선택
* 예: 예측 결과 [5]


Iris 분류 실습

# 1. 데이터 생성 및 전처리

* 데이터: seaborn.load_dataset("iris") 또는 sklearn.datasets.load_iris()
* feature X: 꽃받침/꽃잎 길이‧너비 4개 변수
* label y: setosa, versicolor, virginica (문자)

## 전처리 과정

1. X = iris.iloc[:, :-1]
2. y = iris.iloc[:, -1]
3. y → 원핫인코딩

   * LabelEncoder 후 to_categorical
   * 또는 pd.get_dummies 사용
4. train_test_split

   * test_size = 0.2
   * stratify=Y (층화추출)
   * random_state=4
5. 데이터 균형 확인

   * 각 클래스 40/40/40, 10/10/10 정상

# 2. 모델 구성

입력 4 → 출력 3
층 구조 예시:

* Dense(64, relu)
* Dense(128, relu)
* Dropout 0.2
* Dense(50, relu)
* Dropout 0.2
* Dense(30, relu)
* Dropout 0.1
* Dense(3, softmax)

총 파라미터: 약 16,700개

**출력층 softmax** → 다중분류
**은닉층 relu** → 기본 활성화함수


# 3. 모델 학습 설정

model.compile(
loss = categorical_crossentropy,
optimizer = adam,
metrics = accuracy
)

* categorical_crossentropy: 원핫인코딩된 다중분류용 loss
* adam: 기본 옵티마이저

# 4. 모델 학습 (fit)

* epochs: 200
* batch_size: 40
* validation_split: 0.2

### 콜백 추가

EarlyStopping(patience=40)
ModelCheckpoint(filepath, monitor=val_accuracy, save_best_only=True)

CheckPoint 파일명 예:

* iris-007-loss0.7205-acc1.0000.h5
* iris-005-loss0.7852-acc1.0000.h5

EarlyStopping → 과적합 방지
ModelCheckpoint → 최고 성능 모델 자동 저장

# 5. 모델 평가

1) 학습곡선 시각화

* hist.history['loss'], hist.history['val_loss']
* hist.history['accuracy'], hist.history['val_accuracy']
* loss 그래프 + accuracy 그래프 동시에 표시

2) 테스트셋 성능

model.evaluate(X_test, Y_test)

* loss 약 0.15
* accuracy 약 0.93 ~ 0.97

3) 저장된 최고 모델 평가

model_best = load_model('iris-007-loss0.7205-acc1.0000.h5')

성능:

* accuracy 1.0도 가능 (테스트셋 기반)

 4) 혼동행렬(교차표)

* Residual Block 구현

input → Dense(80)
input → Dense(30)

dense2 = Dense(50)(dense1)
add([dense1, dense2])
