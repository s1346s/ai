아래는 **nltk 자연어처리 + 한글 형태소 분석 수업 내용**을 요청하신 **간단 요약 형식**에 맞춰 정리한 것입니다.

---

# (1) NLTK 기본 기능

* 영어 자연어처리 패키지
* 텍스트 전처리: 토큰화(문장·단어), 정규표현식 토큰화, 불용어 처리, 어간추출
* 품사 태깅: `pos_tag()`
* 말뭉치 사용: Gutenberg 등 제공
* 주요 기능

  * `sent_tokenize()` : 문장 분리
  * `word_tokenize()` : 단어 분리
  * `RegexpTokenizer()` : 정규식 기반 토큰화
  * 어간추출: Porter, Lancaster, RegexpStemmer
  * 품사태깅 후 특정 품사(NN 등)만 추출
* 분석 예시:

  * 단어 빈도수(FreqDist)
  * Text 객체의 plot(), dispersion_plot()
  * 워드클라우드 생성 가능

---

# (2) NLTK 실습: Emma 말뭉치 분석

* Gutenberg 코퍼스에서 `austen-emma.txt` 로드
* 3글자 이상 단어만 정규표현식으로 추출 후 POS 태깅
* “Emma” 등장 횟수 및 품사 분포 계산
* 명사(NN, NNS, NNP, NNPS)만 추출하여

  * 총 등장 횟수
  * 고유 명사 빈도 분석
  * 시각화(plot, dispersion plot) 수행
* WordCloud 생성:

  * 토큰 → POS 태깅 → 명사만 연결 → 워드클라우드

---

# (3) 한글 형태소 분석 개요

* 자연어 처리 단계

  * 전처리 → 형태소 분석 → 품사태깅 → 의미 분석(빈도, 연관성)
  * 모델링: RNN·LSTM·Transformer 등
* 활용: 텍스트 분석, 번역기, 챗봇, 맞춤법, 트렌드 분석

---

# (4) 한글 형태소 분석기(KoNLPy & Mecab)

### 공통 기능

* `morphs()` : 형태소 분리
* `nouns()` : 명사만 추출
* `pos()` : 품사 태깅

### 엔진 종류 및 특징

* **Hannanum** : 세밀한 분석, 여러 후보 반환
* **Kkma** : 문장 분석 정확도 우수
* **Komoran** : 안정적, 실무에서 많이 사용
* **Okt** : SNS 텍스트에 강함
* **Mecab** : 가장 빠르고 정확도 우수(추천)

### 품사 예시

* Mecab: NNG, NNP, NNBC → 명사
* Okt: Noun
* Kkma: NNG, NNP 등

### 실습 내용

* 각 분석기별 형태소, 명사, 품사태깅 비교
* 조건에 따른 명사·형용사 추출
* 품사태그 기반 필터링(NC, PA 등)

---

# (5) 말뭉치 사용

* 영어: NLTK Gutenberg
* 한국어: KoNLPy `kolaw`(대한민국 헌법 등 제공)

---

# (6) 워드클라우드 생성

* 단어 리스트 → 문자열로 결합 → WordCloud
* 한글의 경우 **font_path** 설정 필수
* 옵션: 배경색, 색상 맵(colormap), 최대 단어수, 폰트 크기
* 불용어 처리: STOPWORDS + 사용자 정의
* 마스크(mask) 이미지 사용 가능

  * PNG, JPG → numpy array로 변환
  * 전처리(밝은 영역 → 흰색) 가능
* 다양한 이미지 형태(하트, 지도 등)로 워드클라우드 생성
