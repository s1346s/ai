[1] NLTK 기본 기능

* 영어 텍스트 전처리를 위한 대표 패키지임
* 문장 분리, 단어 분리, 정규표현식 기반 토큰화 수행 가능
* 어간추출 Porter Lancaster RegexpStemmer 제공
* 품사 태깅 기능을 통해 단어별 품사 정보를 얻을 수 있음

[2] NLTK 말뭉치와 토큰화

* Gutenberg 등 다양한 말뭉치를 제공함
* raw 텍스트를 불러온 뒤 문장 토큰화와 단어 토큰화를 수행할 수 있음
* RegexpTokenizer로 숫자만 추출하거나 영문자만 추출하는 등 맞춤형 토큰화 가능

[3] NLTK 품사 태깅과 명사 추출

* pos tag 를 이용해 각 단어에 품사를 부착함
* 명사 품사 NN NNS NNP NNPS 만 선택해 리스트로 만들 수 있음
* 품사 기반으로 특정 단어의 등장 횟수와 품사 분포도 분석 가능

[4] NLTK 텍스트 분석 도구

* FreqDist 로 단어 빈도 계산 가능
* Text 객체를 사용해 단어 등장 패턴과 분산 그래프를 시각화할 수 있음
* 추출된 명사들을 연결해 워드클라우드 이미지로 시각화할 수 있음

[5] 한글 형태소 분석 개요

* 전처리 형태소 분석 품사 태깅 의미 분석 등의 과정으로 자연어 이해가 이루어짐
* 한국어의 경우 형태소 단위 분석이 필수적이며 명사 동사 형용사 등을 태깅해 활용함

[6] 한글 형태소 분석기 KoNLPy Mecab

* KoNLPy 에는 Hannanum Kkma Komoran Okt 등 분석기가 포함됨
* Mecab 은 별도 설치가 필요하지만 속도가 가장 빠르고 정확도가 높음
* 각 분석기는 morphs nouns pos 기능을 제공하며 품사 체계는 서로 다름
* 품사 태그를 이용해 명사만 필터링하거나 형용사만 추출하는 등의 작업이 가능함

[7] 한글 말뭉치와 분석

* KoNLPy 에서 kolaw 말뭉치를 제공하며 대한민국 헌법 텍스트를 분석할 수 있음
* 형태소 분석 후 명사 추출 빈도 분석 등이 가능함

[8] 워드클라우드 생성

* 명사 리스트를 공백으로 연결해 텍스트를 만든 뒤 워드클라우드를 생성함
* 한글 사용 시 font path 설정이 필수임
* stopwords 옵션으로 불용어를 제거할 수 있음
* 마스크 이미지를 사용해 특정 모양의 워드클라우드를 만들 수 있음
