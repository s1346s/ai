* prophet : Facebook 개발 시계열 자동 예측 모델

[2] 데이터 불러오기 및 확인

* 한글 폰트 설정 후 시각화 가능

주요 결측 발생 측정소 예: 남산, 세곡, 관악산, 마포아트센터, 서대문구 등

[3] 날짜 처리(측정일시 → datetime)

* 측정일시(int)를 문자열 변환
* YYYY-MM-DD 형식으로 가공
* pandas datetime 타입으로 변환
* 열 순서 재배치 후 측정일시 삭제

최종 컬럼명:
측정일, 측정소명, 이산화질소농도, 오존농도, 일산화탄소농도, 아황산가스농도, 미세먼지농도, 초미세먼지농도

[4] 특정 측정소 필터링 및 시각화

* 예: 공항대로 측정소 데이터 선택
* 미세먼지농도, 초미세먼지농도 시계열 그래프 출력

[5] statsmodels – 시계열 분해(seasonal_decompose)

* 특정 측정소의 미세먼지농도 1개 컬럼만 선택
* 날짜를 인덱스로 설정하여 시계열(ts) 생성

분해 결과 구성 요소

* observed : 실제 관측값
* trend : 장기적 변화 패턴
* seasonal : 주기적 패턴
* resid : 잔차(노이즈)

period=30 설정 → 30일 주기 계절성 분석

[6] Prophet 사용 준비

* Prophet은 ds(날짜), y(값) 두 컬럼만 사용
* df.columns = ['ds', 'y'] 로 수정
* 이후 model.fit(), model.predict()로 예측 가능
