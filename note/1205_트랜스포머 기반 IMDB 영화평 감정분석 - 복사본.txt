[1] IMDB 영화평 데이터 개요

* 5만 개 영화 감상평 (Train 25,000 / Test 25,000)
* 타겟 변수: 0=부정, 1=긍정
* 리뷰는 이미 정수 인덱스로 인코딩된 상태로 제공됨
* 단어 빈도수가 높을수록 작은 번호가 부여됨

[2] 데이터 전처리

* imdb.get_word_index()로 단어→정수 매핑 확인
* id_to_word를 만들어 정수→단어 역변환 가능
* 리뷰 디코딩 함수로 실제 문장 복원 가능
* 리뷰 길이 분석: 최소 11, 최대 2494, 평균 약 238 단어
* pad_sequences로 모든 리뷰 길이를 동일하게 200으로 맞춤

  * truncating='post' : 길면 뒤에서 자름
  * padding='pre' : 짧으면 앞을 0으로 채움

[3] 하이퍼파라미터 설정

* MY_WORDS = 20000 (단어 사전 크기)
* MY_LENGTH = 200 (리뷰 입력 길이)
* MY_EMBED = 32 (임베딩 차원)
* MY_HIDDEN = 64 (은닉 노드 수)
* MY_EPOCH = 15
* MY_BATCH = 200

[4] LSTM 모델 구현

* Embedding(20000, 32)
* LSTM(64, dropout=0.5, recurrent_dropout=0.3)
* Dense(1, sigmoid)
* 이진 분류용 모델

[5] Transformers 인코더 모델 구현

* 입력층 + Embedding
* Positional Encoding: 위치 정보를 Embedding으로 더함
* Multi-Head Attention(num_heads=3, key_dim=32)
* 잔차 연결 + BatchNormalization
* Feed Forward Network(Dense 64 → 32)
* 다시 잔차 연결 + BatchNormalization
* GlobalAvgPool1D로 하나의 벡터로 압축
* Dropout 적용
* 출력층: Dense(2, softmax) → 부정/긍정 분류
* 손실함수: sparse_categorical_crossentropy

[6] 모델 학습 및 성능

* EarlyStopping(patience=5) 적용
* 학습 중 Validation Accuracy 약 85% 근처 도달
* 테스트 데이터 정확도: 약 0.777
* precision: 약 0.762
* recall: 약 0.806
* f1-score: 약 0.783

[7] 혼동행렬

* 실제 0 → 예측 0: 9360
* 실제 0 → 예측 1: 3140
* 실제 1 → 예측 0: 2427
* 실제 1 → 예측 1: 10073

→ 긍정(1) 리뷰에서 더 잘 맞추는 경향 존재

[8] 모델 사용하기

* 입력 리뷰에서 특수문자 제거 → 소문자 변환 → 단어 분리
* 단어를 정수로 인코딩 (사전에 없으면 2로 처리 가능)
* pad_sequences로 길이를 200으로 맞춘 후 모델 입력
* model.predict 결과가 0.5 이상이면 긍정(1), 미만이면 부정(0)
