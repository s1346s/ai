[1] LLM 활용 기본 아이디어

* Ollama: 로컬에서 오픈소스 LLM 실행
* 성능은 GPT·Claude보다 낮지만 개념 학습용으로 적합
* OpenAI: API 기반 고성능 모델 사용
* LangChain: LLM 호출, 프롬프트 관리, 체인 구성 등 제공


[2] Ollama 사용

* 설치 후 모델 다운로드: `ollama pull 모델명`
* LangChain 연동 예시

* `ChatOllama(model="deepseek-r1:1.5b")`
* `llm.invoke("질문")`
* 로컬 기반이므로 빠르고 무료

[3] OpenAI 사용

* `pip install langchain-openai`
* API Key 환경변수 설정 필요
* `ChatOpenAI(model="gpt-5-nano")` 사용
* LLM 응답은 AIMessage 형태로 반환됨


[4] 프롬프트 작성 방식

(1) PromptTemplate

* `{변수}` 포함 가능
* `.invoke({"country":"Korea"})`로 값 전달
* 모델 호출 시 문자열 프롬프트 자동 생성

(2) 메시지 기반 프롬프트

* SystemMessage: 역할/페르소나 설정
* HumanMessage: 사용자 질문
* AIMessage: 예시 답변(few-shot)
* 메시지 리스트 그대로 llm.invoke()

(3) ChatPromptTemplate

* 메시지를 튜플 목록으로 선언
* few-shot + 변수 치환 + system 프롬프트 설정 가능
* `.invoke({"country": "Korea"})`로 최종 프롬프트 생성

[5] OutputParser (출력 형식 제어)

(1) StrOutputParser

* AIMessage → 문자열로 변환
* 특정 형식(예: 도시 이름만) 출력할 때 활용

(2) JsonOutputParser

* LLM 응답을 JSON(dict) 형태로 강제
* 프롬프트에서 JSON 형식으로 답변하라고 지시 필요

(3) Pydantic 기반 구조화된 출력

* 가장 안정적인 구조화 방식
* BaseModel 정의 → LLM이 해당 필드를 채워 반환
* `llm.with_structured_output(Model)` 형태로 사용

[6] LCEL (LangChain Expression Language)

(1) 모든 구성 요소는 Runnable

* PromptTemplate
* LLM(ChatOllama, ChatOpenAI)
* OutputParser

(2) 체인 구성: 파이프(|) 연산자

* 예:
  `chain = prompt | llm | parser`
* `.invoke({"country":"Korea"})` 로 실행

(3) 복합 체인 예시

* 단계1: 힌트로부터 국가 추론
* 단계2: 국가 이름만 출력
* Prompt → LLM → Parser 흐름을 연결
